# applem

**Public pages for the app live in `docs/`.**

- `docs/index.html` · the site. Open it directly, or serve `docs/` with GitHub
  Pages on the `main` branch.
- `docs/assets/` · the copy of the logo the page needs, so the folder stands on
  its own without reaching outside it.

The page carries the install steps. The app itself is unchanged by it, and the
build has no dependencies: one HTML file, one CSS block, one small script.
