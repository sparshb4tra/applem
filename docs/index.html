How it works

Four steps, start to finish.

  1. Paste a playlist linkAny public Apple Music playlist.
  2. Choose a folderWhere the song files should land.
  3. Choose a formatMP3, or WAV for the untouched audio.
  4. DownloadThe folder opens when the run finishes.

Controls

Long runs are meant to be interrupted.

Every run is resumable and every result is checkable, so a playlist that spans an evening is not a problem.

  • PauseStop a long run and leave the finished files alone.
  • ResumePick it back up where it stopped.
  • CancelEnd the run safely.
  • Skip songs already downloadedKeep what is there and fill only the gaps.
  • Verify downloadsCheck that every expected song exists.
  • Retry missingTry the incomplete tracks again.
  • Clear logClears the visible log. Nothing else.

Songs are numbered 001 - Song - Artist.mp3. Anything that could not be matched goes to failed_downloads.txt, and a verification leaves verification_report.txt.

Install

Install it once. Then double-click it forever.

Both setup scripts do the whole job: the dependency, the encoder, and a private environment for the app.

macOS

  1. Install Python 3.10 or newer from python.org.

    Run python3 --version to check.

  2. In Terminal, from the project folder: bash setup/install_mac.sh

    Installs Homebrew and FFmpeg if they are missing, builds .venv, installs yt-dlp.

  3. Open Apple Music Downloader.command.

Windows

  1. Install Python from python.org.

    Run python --version to check.

  2. Double-click setup\install_windows.bat.

    Installs the requirements, and FFmpeg through winget if it is missing.

  3. Open Apple Music Downloader.bat.

By hand, either system:

python -m pip install -r requirements.txt python app.py
  • Python 3.10 or newer
  • yt-dlp
  • FFmpeg, for MP3 conversion
  • macOS or Windows
  1. This does not download from Apple Music. Apple Music supplies the public playlist's track list; the audio is matched on YouTube, so odd covers and live versions can turn up in place of a studio track.
  2. FFmpeg is required for MP3 conversion only. WAV needs nothing beyond the steps above.
